## ViewIt_Sorter_WebApp

### 📘 Overview

A web app prototype built with Dart and Flutter Web. Designed to explore sorting algorithms through visual interaction, with a clean UI to display data structures in real-time. Originally created during college as part of my app-dev journey.

---

### 🛠️ Tech Stack

* **Frontend:** Flutter Web, Dart
* **Deployment:** Web App (local development)

---

### 🚧 Project Status

Complete and stable — Developed to learn UI rendering, algorithm visualization, and Dart web deployment. No further updates currently planned.
